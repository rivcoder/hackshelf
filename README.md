# Hackshelf

> **Never miss a hackathon deadline again.**  
> Save hackathons from Devfolio, Unstop, Devpost, MLH and more in one unified shelf. See what closes first, track your application pipeline, and keep team notes in one place.

![Hackshelf Logo](img/logo.png)

---

## ✨ Features (v1)
- **One Shelf, Sorted by Deadline**: Automatically calculates urgency (days left) with color-coded status chips.
- **Auto-Detection**: Pasting a hackathon link automatically identifies the platform (Devfolio, Unstop, Devpost, MLH, etc.).
- **Pipeline Tracking**: Track statuses from `Interested` $\to$ `Registered` $\to$ `Team formed` $\to$ `Submitted` $\to$ `Result`.
- **Team Notes & Chat Links**: Keep group chat links and teammate names directly attached to each hackathon.
- **Offline & Zero-Barrier**: Built with local-first storage. Start using immediately without forced signups.
- **Backup & Restore**: One-click JSON export and import to safeguard your hackathon list.
- **Dark Luxury Aesthetic**: Custom dark theme with micro-interactions, smooth reveals, and motion accessibility.

---

## 🛠️ Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, ES6+ JavaScript (Zero external runtime dependencies).
- **Styling**: Modern CSS variables, flexbox/grid layout, and responsive breakpoints.
- **Backend / Database**: Supabase (PostgreSQL with Row Level Security).

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 3000

# Or using Node.js / npx
npx serve .
```

Then visit `http://localhost:3000`.
